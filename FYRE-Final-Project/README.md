# FYRE Sensing The World Final Project

My group's final project (members: Claire Volinski, Euan Maxwell, and Layla Neresko) was a box constructed to house historical items. These items can range from older books to delicate artifacts, with an automated preservation system to maintain optimal conditions.

## Project Overview

Our preservation system monitors and controls environmental conditions inside the storage box using sensors and automated controls.
